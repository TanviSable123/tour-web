# 🌍 WanderPlan - Interactive Tour & Trip Planning Web App

A modern, responsive, and feature-rich interactive website for creating, customizing, and organizing travel itineraries.

## ✨ Features Included

1. **Interactive Day-by-Day Itinerary Builder**:
   - Manage multi-day trips with custom day themes, dates, and weather forecasts.
   - Add, edit, reorder (▲/▼), and delete activities.
   - Assign time slots, durations, estimated costs, locations, and categories (Sightseeing, Dining, Transport, Stay, Experience, Shopping).
   - One-click smart recommendations tailored to the tour destination.

2. **🗺️ Interactive Route & Waypoint Simulator**:
   - Dynamic SVG map canvas plotting daily stops in chronological order.
   - Visual route paths with distance calculations (~km) and estimated travel durations.
   - Interactive waypoint pins that open activity details on click.

3. **💰 Real-Time Budget & Expense Tracker**:
   - Total budget target vs. planned spending tracker with dynamic progress bars and status alerts.
   - Cost per person calculator based on traveler count.
   - Itemized spending category breakdown (Accommodation, Food, Transit, Sightseeing, Activities, Shopping).
   - Quick expense logging tool for on-the-go cost capture.

4. **🎒 Smart Packing Checklist**:
   - Categorized packing assistant (Documents, Electronics, Clothing, Health, Gear).
   - Checkbox tracking with real-time completion progress ring.
   - Custom item generator.

5. **📂 Tour Presets & Backup**:
   - Pre-loaded curated itineraries:
     - 🇯🇵 **Tokyo & Kyoto, Japan** (7 Days)
     - 🇫🇷 **Paris Romance & Art, France** (5 Days)
     - 🇨🇭 **Swiss Alps Adventure, Switzerland** (6 Days)
     - 🇮🇩 **Tropical Bali Retreat, Indonesia** (6 Days)
   - Multi-currency support (`$`, `€`, `£`, `₹`, `¥`).
   - Export full tour data as `.json` or print clean, printer-friendly itinerary sheets.
   - Dark / Light mode toggle.

---

## 🚀 How to Run

Simply double-click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari). No build steps or server setup required!
